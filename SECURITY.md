# Security Policy

This organization publishes small tools and utilities.

- **No live write pipes.** Our tools never write to your engineering databases or licenses from a remote service; imports are always an explicit, local, human-approved step.
- If you believe you found a vulnerability in one of our tools, please open a **private security advisory** on the affected repository instead of a public issue.

We aim to acknowledge reports within a few days; this is a small independent project, not a vendor with a dedicated security team.
